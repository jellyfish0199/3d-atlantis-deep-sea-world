# 亚特兰蒂斯 · 深海圣城

一座沉在海底的白色圣城，一场安静的深海散步。

你在清晨的广场上醒来：海神雕像守着喷泉，五只小猫坐在泳圈里打盹，远处的水晶秋千下淌着一汪极光色的水。这里没有任务、没有倒计时——想玩什么，全凭你的好奇心。

**怎么玩一句话版：** 用左侧「探索指引」飞到各个地点，然后**点一切看起来能点的东西**：雕像、书、贝壳、河面、小猫、电话亭……每一处都会回应你。

---

## 开始游玩

1. 打开页面，等进度条走完（首次约加载 10 MB，之后浏览器会缓存）。
2. 默认是「**浏览**」模式：拖拽旋转、滚轮缩放、右键平移。
3. 想自己走路就切「**漫游**」：点击画面锁定鼠标，`WASD` 移动、`Shift` 奔跑、`Esc` 释放鼠标，再按一次退出漫游。
4. 手机：单指旋转、双指缩放平移；漫游时左下角出现摇杆，推到底就是奔跑。

## 你可以做的事

### 🌊 让河水换颜色
河水平时是**蓝色**。点一下河面，它会变成**落霞粉**；再点一下变成**极光色**，来回切换。
- 选「黄昏」时，河水**默认就是粉色**的。
- 每种颜色都藏着一个小故事：粉色是一封写了很多年的情书，极光色是一道迷路的北极光。点河面就能听，极光那段还可以写下一句你想念的人。

### 🐚 收集三枚贝壳里的记忆
广场、楼梯口、长廊各睡着一枚珍珠贝壳。**点击贝壳**，壳盖会从中间的缝隙张开，珍珠里升起一张记忆卡片——那是人鱼守书人留下的三段回忆：
- 白玫瑰与水母（广场）
- 海边的车站（楼梯口）
- 窗边的午后（长廊）

卡片会**随手机陀螺仪倾斜**（手机上点一下允许授权；电脑上跟鼠标走），带镭射反光。**点击图片或「保存到相册」**就能把它存下来。

### 📖 翻开《潮汐之书》
图书馆讲台上一本会说话的书，共 **18 页**，记着圣城一万年的秘密：海神的银三叉戟、落霞之河的来历、五只守门猫、极光的传说……
- **点书** → 封面翻开；**再点书或在对话里选「翻到下一页 →」** → 一页页翻过去，纸页会真的弯曲翻动。
- 在对话里选「我能在你这里写下名字吗」，你的名字会**印在书里的「访客名录」**那一页，留给下一个翻开它的人。

### 🐱 打招呼与收集回应
- **五只随宠**：嘤嘤子、咪奈花、浪浪仙、球棒狸、晴天鸟鸟，泡在广场两侧水池的泳圈里。点它们会**跳起来自我介绍**。
- **猫糕小船**：右侧河上游停着一艘小船，船上住着**萤绒绒、墨镜猫咪、谐乐小喵**。点任何一只猫糕（或点船身），它会探出来说「你好，我是……」。
- **小黄鸭**：广场水面上还有八只，点一下会「嘎！」。

### 🧜‍♀️ 听人鱼唱歌
图书馆里，一道人鱼的全息虚影从投影仪里升起。**点她**，她会为你唱《美人鱼沃雅尼莎》，光影会跟着歌声呼吸、闪烁。

### ☎️ 在海底打一通电话
圣城外的电话亭，听筒连着一千年前的某个下午。拿起它，可以听那头的声音，也可以**留下一句想寄出去的话**——大海会替你保管。

### 🎡 荡秋千
水晶珊瑚下的秋千，脚下是一汪**极光色的水**。点击秋千坐上去，拖动屏幕环顾四周，荡到最高处能看见远处的河。「离开秋千」随时下来。

### 🕐 换时间与天气
底部可以切换**清晨 / 黄昏 / 夜晚 / 暴风雷雨**：光照、水色、灯光、水母亮度都会变；夜晚路灯会亮，暴风雨会有闪电。同一座城，四个样子。

### 🗿 和海神聊两句
广场中央的雕像可以对话：读底座铭文、在雕像前许愿、问问为什么三叉戟是银色的。

## 部署到 GitHub Pages

纯静态站点，**无需构建**。页面全部使用相对路径，放在仓库子目录（`/仓库名/`）下也能正常加载。

1. 新建仓库，把本目录全部文件推到仓库根目录（`index.html` 在根）。
2. **Settings → Pages** → Source 选 **Deploy from a branch** → `main` / `/ (root)` → 保存。
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

### 本地预览

直接双击 `index.html` 会因浏览器 ES 模块跨域限制打不开，请用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 性能与设备

- 手机与低配设备自动切换轻量模型（更小的贴图与面数）；也可在网址后加 `?low` 强制启用。
- 加 `?nobloom` 可关闭泛光，进一步提速。
